Transfers items from a chest to your inventory without exceeding your carry weight limit.

# Demo

## Restock wood

![Restock wood demo](https://i.imgur.com/LgQ1TSn.jpeg)

# Usage

1. Open a container.
2. Pick the item: point the mouse cursor at it, or select it with a left click.
3. Press the hotkey (default: Shift + R).

Only the items identical are transferred. The transfer never pushes you over your maximum carry
weight.

# Configuration

Settings can be changed in-game (using ConfigurationManager) or directly in
`BepInEx\config\orax.Restock.cfg`.

# Installation

This mod is client-side only. You do not need to install it on the server.

## Using a mod manager (recommended)

You can install the mod using Vortex or Gale.

## Manual

Install [BepInExPack for Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/),
then copy `Restock.dll` to `Steam\steamapps\common\Valheim\BepInEx\plugins\Restock\`.
